# cwmagoon.github.io

Personal academic website of Connor Magoon, served at <https://cwmagoon.github.io>
with GitHub Pages.

The site is a single page, `_pages/about.md`, rendered by Jekyll through
`_layouts/default.html`. Figures live in `images/` and the CV in `files/`.

Preview locally:

    bundle install
    bundle exec jekyll serve --config _config.yml,_config.dev.yml
